How to use it

1
Go to prechained.com/capture and submit your package to create a cryptographic archive record.
2
Copy a badge snippet above and paste it into your README.md.
3
Optionally link directly to your package page: https://prechained.com/package.html?name=YOUR-PKG&ecosystem=npm
4
Add the Prechained GitHub Action to verify on every push automatically.
The badge links to prechained.com — no tracking, no cookies, no referrer data collected. AGPL-3.0.
