Live Threat Feed

Packages where a new capture differs from the package's own prior history in a way consistent with a supply-chain attack. Every finding is evidence-backed and links to verifiable cryptographic receipts. Detection runs at capture time, comparing each version against earlier captured versions of the same package.

What this is and isn't: Each finding is a concrete, checkable difference between a new version and prior captured versions — not a verdict of malice. A detector only fires when prior history exists to compare against. Verify the receipts and read the evidence before drawing conclusions. Detection covers what Prechained captures: it is not a complete view of every package on earth. An empty feed is the expected normal state — content substitution under a fixed version is rare, so most days there is nothing to report. The detectors run on every capture regardless.
